# أنقذوا البطل بجدول الضرب

لعبة ويب ثابتة (HTML/CSS/JS) بدون أي خادم.

## النشر على GitHub Pages (مجاني ولا يتوقف بسبب الحدود)
1. أنشئ مستودعًا جديدًا على GitHub، وارفع كل محتويات هذا المجلد (index.html و style.css و game.js ومجلد assets).
2. من المستودع: Settings ← Pages.
3. في Source اختر: Deploy from a branch، ثم Branch: main و Folder: / (root)، ثم Save.
4. بعد دقيقة يظهر الرابط: https://اسمك.github.io/اسم-المستودع/

## التخصيص
كل الإعدادات في أعلى ملف game.js (العنوان، وقت السؤال، عدد الأسئلة، ...).
لتغيير صورة البطل أو الشعار استبدل الملفين في مجلد assets (أو غيّر المسار في game.js).
